# Research History

This repository was opened publicly in May 2026, but the Guandan AI project
predates the public snapshot. The private working archive contains battle logs,
evaluation records, research reports, and experimental checkpoints dating back
to April 2026. This page summarizes the real development path without
publishing private battle logs, machine configuration, or model weights.

## Archive Scope

As of May 31, 2026, the private working archive contained:

## Timeline

### April 27-28: Rules, baseline play, and paired gates

The first retained phase established deterministic dealing, legal-action
generation, partnership scoring, heuristic play, and battle logging. Direct
policies were tested with paired seat swaps so an evaluation would not depend
on one favorable seating arrangement.

The selected public records include v7 paired gates against v5 and v6. The
published CSV files contain 400 games for each matchup.

### April 29: Search labels and guard-aligned releases

The next phase added public-information search labels, value calibration, and
tactical guards. The retained paired gates show a sequence of incremental
experiments:

| Candidate | Opponent | Games | Wins | Win rate |
| --- | --- | ---: | ---: | ---: |
| v8 searchmix | v7 | 200 | 135 | 0.675 |
| v9 broad-hard | v8 searchmix | 100 | 60 | 0.600 |
| v10 self-play | v9 broad-hard | 60 | 33 | 0.550 |
| v11 guard-aligned | v10 self-play | 60 | 37 | 0.617 |

Not every experiment was accepted. Candidate pruning looked promising in
offline recall checks but failed a larger head-to-head gate, so it remained
optional. This became an important project rule: offline metrics are evidence,
not a release decision.

### May 2-11: Human-loss replay and counterfactual analysis

Human battle failures were mined into regression cases. The project added
short-race exact search, conservative pass guards, candidate-retention
diagnostics, Team-Q risk experiments, and replay counterfactual checks.

Several fixes stayed research-only because they improved one failure family
while regressing against an older opponent style. Older policies remained in
the evaluation pool to catch these tradeoffs.

### May 12-17: League data and belief-search experiments

The project expanded into league self-play, public-state scaffolds,
rejection-first safety studies, and an offline belief-PUCT prototype. A remote
stability aggregate completed 960 games and 52,352 PUCT decisions without a
crash. That result was treated as wiring evidence, not proof of playing
strength, because some search components were still placeholders.

### May 29-31: Outcome-first full-information research

Later offline experiments tested policy-gradient and AlphaZero-like routes
with full-information teachers. These experiments deliberately kept all legal
root actions available so old candidate pools could not hide novel plays.

This branch found useful search and training bugs, including accidental root
action pruning and misleading rollout-cap behavior. It remains offline
research: full-information teachers are not fair live opponents and are not
published as runtime defaults.

### June 1-3: Outcome-oracle teacher and student checks

The V45 route continued with outcome-gated full-information search. A
three-computer June 1 holdout crossed 80% overall but still failed per-opponent
targets, so it remained research-only. Follow-up June 2 sweeps retained a
bounded outcome-oracle teacher with targeted ambiguous-pass refinement. The
teacher reached 166/192 paired swapped-seat wins across v5/v6/v7/v18 and became
eligible for policy-only student-data preparation.

June 2 also added semantics-preserving rule and hand-evaluation optimizations:
106 tests passed, 2,880 random small hands matched the legacy recursion, and
5,445 retained states reproduced the same legal-action sets.

On June 3, a policy-only student fit the teacher package better offline, but
fresh gameplay checks were mixed. It remains a valid offline distillation
artifact, not a retained gameplay checkpoint or runtime default. See
[`docs/RECENT_PROGRESS_2026_06.md`](RECENT_PROGRESS_2026_06.md).

## Release Philosophy

The project uses a conservative release boundary:

1. Keep public-information runtime models separate from full-information
   research teachers.
2. Test candidate changes against older opponent styles, not only the newest
   model.
3. Prefer paired seat-swapped gates and full-game outcomes over isolated
   offline metrics.
4. Keep rejected experiments documented instead of silently promoting them.
