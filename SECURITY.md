# Security Policy

## Supported Versions

Guandan AI is currently an alpha research project. Security fixes are applied
to the latest revision on the default branch.

## Reporting a Vulnerability

Please do not publish secrets, private battle logs, or machine-specific paths
in an issue. For a sensitive report, contact the repository maintainer through
the email address listed on the maintainer's GitHub profile.

The public repository intentionally excludes model checkpoints, datasets,
private logs, and deployment configuration.
