# Replay Examples

These traces are generated by the public heuristic baseline:

```bash
python tools/play_demo.py --seed 21 --trace examples/replays/demo_seed21.json
python tools/play_demo.py --seed 42 --trace examples/replays/demo_seed42.json
python tools/play_demo.py --seed 2026 --trace examples/replays/demo_seed2026.json
```

Open `tools/replay_viewer.html` in a browser and select any trace to inspect the
game. The traces contain public state transitions and intentionally omit full
player hands.
